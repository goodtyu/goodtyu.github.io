DockRoot 使用手册

一、DockRoot 简介

DockRoot 是一个轻量版 Docker。

特点：

  • 用法与 Docker 类似
  • 不需要 Docker Daemon
  • 不依赖 OverlayFS
  • 不依赖 Cgroup
  • 不需要 systemd
  • 基于 ruri 实现
  • 支持更多 Linux 环境
  • 内存占用极低

缺点：

  • 必须使用 Root 权限运行
  • 无网络隔离（相当于 Docker Host 模式）
  • 不支持 Docker Compose
  • 不支持 Docker Network
  • 不支持 Docker Exec
  • 不支持 Docker Inspect
